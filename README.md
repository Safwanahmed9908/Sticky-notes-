# 📝 Sticky Notes Application

A simple and user-friendly Sticky Notes web application built using React.js, HTML, CSS, and JavaScript. It allows users to create, edit, and delete digital notes while automatically saving their data in browser Local Storage.

## 🚀 Features

- ➕ **Add Notes:** Create new sticky notes easily.
- ✏️ **Edit Notes:** Update note titles and content.
- 🗑️ **Delete Notes:** Remove unwanted notes.
- 💾 **Auto Save:** Automatically saves notes using browser Local Storage.
- 📅 **Date and Time:** Displays the last updated date and time.
- 📱 **Responsive Design:** Works on desktop and mobile devices.
- 🎨 **Simple Interface:** Clean and attractive sticky note layout.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Browser Local Storage

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Safwanahmed9908/Sticky-notes-.git
```

### 2. Open the Project Folder

```bash
cd Sticky-notes-
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Application

```bash
npm start
```

The application will be available locally through the server URL displayed in your terminal.

## 💡 How to Use

1. Open the application in your browser.
2. Click the **Add New Note** button.
3. Enter your note title and content.
4. Edit your notes whenever required.
5. Your notes are automatically saved in browser Local Storage.
6. Click the delete button to remove a note.

## 🎯 Project Objective

The main objective of this project is to provide a simple digital note-taking application that helps users organize their thoughts, reminders, and important information efficiently.
